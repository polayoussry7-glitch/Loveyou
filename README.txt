مشروع عيد ميلاد أونا - ملفان أساسيان

1) index.html
   الموقع كله في ملف واحد: HTML + CSS + JavaScript + الصورة + الأغاني + الفيديو.
   لا يحتاج ملفات وسائط منفصلة ولا خطوط من الإنترنت.

2) server.js
   سيرفر Node.js مستقل يستقبل الرسائل ويعرضها لكل زوار الموقع.
   يستخدم وحدات Node.js المدمجة فقط، ولا يحتاج قاعدة بيانات أو خدمة خارجية.
   عند أول رسالة ينشئ messages.json تلقائيًا بجوار الملفين.

التشغيل:
   node server.js
ثم افتح:
   http://localhost:3000

مهم بخصوص Vercel:
   هذا السيرفر يحتاج استضافة تشغّل Node.js كعملية دائمة وتسمح بحفظ ملف messages.json
   على قرص دائم. Vercel لا يشغّل server.js بهذه الطريقة، وملفات الكتابة داخله ليست
   تخزينًا دائمًا. لذلك ارفع الملفين على استضافة Node.js/VPS أو جهاز/سيرفر تملكه.
   لو قررت استخدام Vercel تحديدًا، فسنحتاج تخزينًا خارجيًا أو تصميم API serverless
   مع قاعدة بيانات مناسبة.

ملاحظة:
   الرسائل عامة لكل زوار الموقع. السيرفر يضع حدًا لطول الرسالة ومعدل الإرسال الأساسي،
   لكنه لا يوفر لوحة حذف/إدارة للرسائل في هذه النسخة.
